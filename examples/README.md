# HWTT Analyzer Examples

These files are sample inputs for the supported analyzer modes.

- `PTI_Equipment_Output_Example.xlsm`: PTI workbook example
- `Troxler_Equipment_Output_Example.xls`: Troxler workbook example
- `Instrotech_LEFT_Equipment_Output_Example.txt`: Instrotech left-side report example
- `Instrotech_RIGHT_Equipment_Output_Example.txt`: Instrotech right-side report example
- `Custom_Excel_Template.xlsx`: compact custom-column workbook example

The Instrotech examples use the same `[GRAPH]` row structure parsed
from supported Instrotech `.txt` and `.docx` reports.
