# Contributing

The current public package is distributed as a Windows executable and does not include the application's source code.

For bug reports and feature requests, please open a GitHub Issue with:

- a clear description of the problem or requested feature;
- the input-file type involved (PTI, Troxler, Instrotech, or custom Excel);
- the application version;
- the Windows version;
- relevant screenshots or sanitized sample data when possible.

Do not upload confidential project data, personally identifiable information, or proprietary laboratory records.
